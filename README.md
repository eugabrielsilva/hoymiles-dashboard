# Minha Usina Solar

Este é um dashboard desenvolvido em React + Vite para exibir informações de usinas solares que usam microinversores da marca Hoymiles. Utiliza a conta e os dados da API do S-Miles Cloud para buscar as informações da usina solar.

O dashboard também oferece alguns insights para o consumidor final saber sobre o rendimento da sua usina, mesmo que não tenha conhecimentos técnicos sobre o assunto.
